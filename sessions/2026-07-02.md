## Milestone 2 — Two-user login (Express session), gate the API

**Status:** Code complete — blocked on human setup for acceptance test

### Changes

- **`package.json` / `package-lock.json`:** Added `express-session`, `bcryptjs`, and `@types/express-session`.
- **`server.ts`:**
  - Session middleware with `SESSION_SECRET` from `.env` (`httpOnly` cookie, `secure` in production).
  - `POST /api/login` — validates username/password against `PARENT_A_*` / `PARENT_B_*` env vars via `bcryptjs.compare()`; sets `req.session.parentType`; returns `{ parentType, parentName }`.
  - `POST /api/logout` — destroys session, clears cookie.
  - Auth middleware on all `/api/*` routes after login handler — returns `401` if `req.session.parentType` is unset.
