# design-sync notes — Baby Tracker

This repo is an **application** (`react-example`), not a component-library package. The
design-system surface is a hand-written barrel, `src/design-system.ts`, re-exporting 12
reusable presentational components. Nine icons + `SleepTimer` were extracted out of the
6.5k-line `src/App.tsx` into `src/components/icons.tsx` and `src/components/SleepTimer.tsx`
(App.tsx now imports the ones it uses). `DateTime24` and `InstallAppButton` were already
standalone.

## Build mechanics
- **No component build / no shipped `.d.ts`.** The converter runs with `--entry ./src/design-system.ts`
  (source barrel). esbuild bundles it fine; ts-morph prop extraction cannot (no `.d.ts`), so it
  stubs every prop as `[key: string]: unknown`.
- **Props are hand-written in `cfg.dtsPropsFor`** for all 12 components. This is the API contract
  the design agent sees. **If a component's real props change, update `dtsPropsFor` to match.**
- **`[DTS_REACT]` warning is expected and harmless** — `@types/react` isn't in the repo's
  `node_modules`, but no component's props extend React utility types, and all props are hand-written.
- **CSS is a scoped Tailwind v4 build.** `cfg.buildCmd` runs `@tailwindcss/cli` over
  `.design-sync/tailwind-input.css`, which uses `@import "tailwindcss" source(none)` + explicit
  `@source ../src/components` and `@source ./previews`. Without `source(none)`, Tailwind auto-scans
  the whole app and the stylesheet balloons to ~83KB (vs ~14KB scoped).
  - **Any new utility class used in a preview requires re-running `buildCmd` BEFORE `package-build`**,
    or the class won't be in `ds.css` and the preview renders unstyled.
  - `cssEntry` = `.design-sync/.cache/ds.css` (gitignored; regenerated by `buildCmd`).
- **Dark theme by design.** `styles.css` sets `body { background:#020617 }` — every design built
  with this DS gets a dark slate canvas. Components are built for dark backgrounds.
- **Font:** Heebo via a remote Google Fonts `@import` (`[FONT_REMOTE]`, loads at runtime — nothing
  to ship). The app is Hebrew / RTL.

## Re-sync risks (watch-list)
- **`dtsPropsFor` can silently drift from source.** It is hand-maintained. If someone changes a
  component's props in `src/components/*`, the emitted `.d.ts` will NOT reflect it until `dtsPropsFor`
  is updated. On re-sync, spot-check the 12 prop bodies against source.
- **Icons extracted from App.tsx.** Seven type-glyph icons (`IconBreast`, `IconBottle*`, `IconPoo`,
  `IconPeeDrop`, `IconWeightScale`, `IconSleepMoon`) were unused in App.tsx (only kept alive by a
  `void [...]` statement, now removed). They are exported solely for the design system. If App.tsx is
  refactored, confirm the barrel still resolves.
- **Scoped Tailwind output is only as complete as the `@source` globs.** New components must live
  under `src/components` (or the globs must be widened) or their classes won't be compiled.
- **Preview grades assume the dark canvas.** If `styles.css`'s dark base is ever dropped, every card
  regrades.
